# Gour Tent and Catering — website starter

This is a responsive, single-page static website for Gour Tent and Catering in Mohali.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript in one file)
- `README.txt` — publishing and editing instructions

## Before publishing
1. Open `index.html` in a browser and check it on your phone.
2. Replace the sample/stock photos with real photos of your own events. Search for `images.unsplash.com` in `index.html` to find the image URLs.
3. Confirm that every listed service is genuinely offered.
4. Add the full business address only if you want it publicly displayed and it is appropriate for customers to visit.
5. Check the phone number, WhatsApp and email.
6. Add a favicon/logo if you have one. The current circular “G” is a text-based placeholder.

## Cheapest publishing path: GitHub Pages + custom domain
GitHub Pages can host a static website for free. The custom domain itself costs money and must be purchased from a domain registrar; price and availability vary.

1. Create/sign in to a GitHub account at https://github.com/
2. Create a **public** repository named `gour-tent-catering` (or another name).
3. Upload `index.html` and `README.txt` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will show a `https://YOUR-USERNAME.github.io/gour-tent-catering/` address after deployment. Wait for the first build to finish.
7. Buy your preferred domain from a registrar after checking availability. A name such as `gourtentandcatering.in` is only a suggestion; availability is not checked.
8. In GitHub Pages settings, enter your custom domain and save.
9. At your domain registrar, add the DNS records GitHub Pages currently instructs you to add. Follow GitHub's live documentation because exact DNS instructions can change: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
10. Enable **Enforce HTTPS** once GitHub offers it.
11. Test the website on mobile, test the WhatsApp form, and then add the website URL to your Google Business Profile.

## Alternative
Netlify can also host a static website on a free tier. You can upload/deploy the site and connect a custom domain, but you still have to buy the domain and configure DNS.

## Important limitations
- The site is not live just because these files exist.
- This site does not include a database, payment system or automatic booking calendar.
- The enquiry form prepares a WhatsApp message; it does not send it automatically.
- The gallery currently uses external sample images. Replace them with photos you own or have permission to use before publishing.
- Search ranking is not guaranteed by creating a website. Keep your Google Business Profile accurate and consistent.
